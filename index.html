Admin Database

Fungsi maintenance database. Sebelumnya harus dijalankan manual dari Apps Script — sekarang bisa langsung dari sini.

Isi ID Kosong
Kasih ID baru (RDI-YYYY-XXX) ke semua item di Master_Item yang ID_Item-nya masih kosong. Item yang sudah punya ID tidak disentuh.
Kalkulasi Ulang Stok
Hitung ulang Stok_Saldo & Stok_Per_Rak dari nol berdasarkan seluruh Transaksi_Log. Pakai ini kalau saldo terasa tidak sesuai atau habis edit manual di Sheet.
Cari Item Yatim
Deteksi ID_Item yang punya transaksi/saldo tapi tidak punya baris di Master_Item. Hanya deteksi — perbaikan tetap manual.
Cari Baris Kembar
Deteksi baris Master_Item dengan Nama + Spesifikasi identik tapi ID berbeda. Hanya deteksi — penggabungan tetap manual.
Resync Master List
Isi ulang daftar Rak dari data aktual + dedup Vendor/Unit/Kategori (case-insensitive, mis. "Acme"/"ACME" jadi 1 entri).
Cari ID Collision (Critical)
Deteksi 1 ID_Item yang dipakai >1 barang berbeda (saldo tercampur). Barang yang aman dipisah bisa langsung dieksekusi dari sini; sisanya wajib direview manual dulu.
