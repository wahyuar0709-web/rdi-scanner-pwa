### A5-01 — Modal detail riwayat menampilkan teks HTML mentah

- **Keparahan:** HIGH (Hard Gate — teks rusak yang benar-benar terlihat user)
- **Lokasi:** `index.html` baris 3797–3798, `showHistCardDetail()`
- **Bukti:** nilai baris pertama dinyatakan memuat markup
  `'<svg class="ic" ...><use href="#i-up"/></svg> Barang Masuk'`, lalu seluruh nilai
  di-escape saat render: `'<div class="item-field-val">'+xe(String(f[1]))+'</div>'`.
  `xe()` (js/util.js baris 29) meng-escape `<`, `>`, `&`, `"`.
- **Dampak:** setiap kali operator membuka "Lihat Detail" dari kartu riwayat semua-transaksi,
  field **Jenis Transaksi** menampilkan string harfiah
  `<svg class="ic" aria-hidden="true"><use href="#i-up"/></svg> Barang Masuk`
  sebagai teks, bukan ikon + label. Teks panjang ini juga meluber layout di HP.
- **Reproduksi:** buka tab Riwayat (semua transaksi) → hasil apa pun → kartu transaksi →
  "Lihat Detail ›" → lihat baris pertama di modal `modal-hist-card-detail`.
- **Saran perbaikan:** kelolaskan markup vs teks: ikon dirender langsung di template
  (di luar escape), hanya label `Barang Masuk`/`Barang Keluar` yang di-escape, atau
  ganti nilai jadi teks polos dan sisipkan ikon via kelas CSS.
- **Status verifikasi:** temuan statis, tertegun di pembacaan kode (L1). L2 runtime: NOT TESTED.

### A5-02 — scanner.html mematikan zoom

- **Keparahan:** MEDIUM (Purpose-Gate — human)
- **Lokasi:** `scanner.html` baris 5: `viewport ... user-scalable=no`
- **Bukti:** atribut `user-scalable=no` ada di satu-satunya viewport; `index.html`
  tidak melakukan ini. Halaman scanner menampilkan pesan operasional yang panjang
  ("Izin kamera ditolak. Buka Pengaturan browser → izinkan kamera.") yang operator
  mungkin perlu perbesar.
- **Dampak:** melanggar WCAG 1.4.4 (text resize) — teks status/error tidak bisa diperbesar;
  untuk operator berusia / mata lemah di lingkungan gudang ini nyata mengeluarkan orang.
- **Reproduksi:** buka `scanner.html` langsung, coba pinch-zoom — diblokir.
- **Saran perbaikan:** hapus `user-scalable=no` (biarkan `maximum-scale` default).
- **Status verifikasi:** L1 statis PASS. L4 perangkat: NOT TESTED.

### A5-03 — scanner.html tanpa penghormatan prefers-reduced-motion

- **Keparahan:** MEDIUM (Purpose-Gate — motion)
- **Lokasi:** `scanner.html` baris 27–30 (`.scanline` `slide` 2.2s infinite), 57–59 (`.spin` 0.8s infinite)
- **Bukti:** `index.html` membungkus banner dunia animasi dengan
  `@media(prefers-reduced-motion:reduce)` (3 titik, lihat sebelumnya) dan token durasi,
  tapi di scanner.html tidak ada satu pun media query gerak.
- **Dampak:** headbanging garis pindai dan spinner berputar terus bagi operator
  vestibular / mag; gaya app yang dinyatakan di `DESIGN.md` (MOTION 1, semua
  non-esensial berhenti saat reduced-motion) tidak konsisten antar permukaan.
- **Reproduksi:** set OS ke Reduce Motion → buka scanner.html → scanline tetap berjalan.
- **Saran perbaikan:** tambahkan `@media (prefers-reduced-motion: reduce)` yang
  menghentikan `.scanline` animasi (spinner loading boleh tetap — itu fungsional).
- **Status verifikasi:** L1 statis PASS. L2: NOT TESTED.

### A5-04 — Indikator fokus form add/edit hanya perubahan warna border 1px

- **Keparahan:** MEDIUM (Purpose-Gate — focus states, konsistensi pola)
- **Lokasi:** `index.html` rule `.edit-field input:focus,.edit-field select:focus{outline:none;border-color:var(--amber)}`
- **Bukti:** pola lain di file yang sama memakai indikator lebih kuat:
  `input:focus` global dan `select.sel:focus` = border biru + ring 3px
  (`box-shadow:0 0 0 3px ...`), `.hist-search-input` = `focus-visible` outline 2px.
  Sheet Tambah/Edit Item — dua form yang paling sering diisi admin — justru pola paling lemah.
- **Dampak:** saat mengetik cepat di gudang, perubahan border 1px abu→amber mudah
  terlewat; tidak melanggar 4.7 minimum (masih terlihat), tapi melanggar konsistensi
  pola fokus yang sudah resmi di file yang sama (human skill: satu pola fokus untuk semua).
- **Reproduksi:** keyboard/Tab ke field "Nama Material" di sheet Tambah Item Baru
  vs Tab ke field pencarian — indikatornya beda jauh kekuatannya.
- **Saran perbaikan:** samakan dengan pola ring: `outline:none` + `box-shadow:0 0 0 3px var(--amber-dim)`.
- **Status verifikasi:** L1 statis PASS. L2: NOT TESTED.
